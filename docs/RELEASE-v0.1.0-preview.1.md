# v0.1.0-preview.1 - bounded synthetic journal and reconciliation

Self-contained Windows x64 and Ubuntu24.04/glibc x64 preview bundles; verify the
known-key signed checksums before extracting. Fixed LAB/scale2 balanced integer
posts, exact same-content retry receipts, conflict rejection, offline synthetic
statement comparison and readable JSON/text reports. Matching-OS CI executes each
actual archive; release aggregation reuses those tested archives without rebuilding.

Source tests include actual owned child interruption before/after commit, lost-response
receipt recovery, two concurrent local clients, full-capacity replay, actual storage
class/schema/trigger/receipt tampering, duplicate counts and report failures.
Fault workers are excluded from shipped bundles. Existing hosts are not clean-OS proof.

Original MIT sample plus retained Microsoft/SQLitePCLRaw/SQLite runtime notices.
Customer/private/shared source/data/configuration/deployment/secrets are excluded.
No real money, bank/broker/account API, trading, performance claim, accounting
certification, power-loss durability, tamper-proof history or distributed exactly-once
guarantee. Provenance/freshness/external completeness remain explicitly unproven.
Signing establishes origin/integrity, not OS signing or a restriction on MIT reuse.
