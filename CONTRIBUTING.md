# Contributing

Use fresh synthetic evidence only. Include version/source commit, OS, exact command,
expected/actual outcome, reason/exit and the smallest reproducible fixture. Preserve
negative results and incomplete runs. Never weaken a check to obtain a green demo.

Do not upload customer-specific code, data, settings, deployment details, secrets,
credentials, account/financial statements, private/shared/employer code, tests,
contracts, schemas or business ideas. Those belong in separate private work.
The public MIT sample and previously published copies retain their existing terms.
Checksum signing verifies origin; it does not prohibit licensed reuse.

Preserve the fixed synthetic LAB/scale2 scope, strict input caps, snapshot identity,
actual storage/schema/canonical receipt checks, retry-before-quota rule and honest
interruption/response-loss distinction. No bank/broker/market API, real money,
SQL/plugin/config/host override, repair/reset or commercial integration in this
preview. Fault hooks remain internal and test workers stay in the excluded test
assembly; no shipped crash/hang flags.

Run the README locked restore and regressions into a fresh directory. Meaningful
changes need behavior-based regressions, current docs and exact-commit Windows/
Ubuntu package checks. Preserve notices and original MIT attribution. Never
rewrite historical tags/assets/signatures or alter other projects/resume/profile.
